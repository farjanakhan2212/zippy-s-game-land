ZIPPY'S GAME LAND  -  app hishebe install korar guide
=====================================================

GITHUB PAGES e rakhar niyom
  1. Zip ta unzip koro. Folder er BHETORER file gulo (index.html, manifest.webmanifest, sw.js, icons folder)
     repo er ROOT e upload koro. Zip file nijei ba folder ta ke upload korle kaj korbe na.
  2. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
  3. 1-2 minute pore address pabe:  https://USERNAME.github.io/REPO-NAME/
  4. Shudhu OI address ta use koro. github.com er file page ba raw.githubusercontent.com er link e install hobe na.

CHECK KORO FILE GULO THIK JAYGAY ACHE KINA (10 second)
  Address er shesh e eigulo likhe khulo. Kono ta 404 dile oi file ta bhul jaygay upload hoyeche.
    .../manifest.webmanifest   (JSON likha dekhabe)
    .../sw.js                  (code dekhabe)
    .../icons/icon-512.png     (Zippy-r chhobi dekhabe)

INSTALL KORA
  Page er upore "Install app" button ta shobsomoy thakbe. Chap dile:
    - Chrome install allow korle sorasori install hobe.
    - Na hole kon browser e ki korte hobe seta likhe dekhabe.
  Android: Chrome e khulo (Redmi/Xiaomi er "Mi Browser" ba Samsung er onno browser diye hobe na).
           Chrome er 3-dot menu > "Install app" ba "Add to Home screen".
  iPhone / iPad: Safari e khulo > Share button > "Add to Home Screen". (Chrome diye hobe na.)
  Computer: Chrome/Edge e khulo, address bar er daan dike install icon ba page er "Install app" button.

JODI TOBUO NA HOY
  - Link ta Messenger/Facebook/WhatsApp/Telegram er vitore khulle install hobe na. "Open in Chrome" kore khulo.
  - Page ta ekbar reload koro (purono version cache e thakte pare), tarpor abar chesta koro.
  - Browser er Settings > Site settings theke ei site er data clear kore abar khulo.
  - Address ta https:// diye shuru hocche kina dekho.

UPDATE DILE
  index.html bodlano porer bar sw.js er prothom line e  const VERSION = 'zippy-v3';  ke 'zippy-v4' koro.
