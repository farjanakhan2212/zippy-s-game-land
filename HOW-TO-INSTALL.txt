ZIPPY'S GAME LAND  -  app hishebe install korar guide
=====================================================

GITHUB PAGES e rakhar niyom
  1. Zip ta unzip koro. Folder er BHETORER file gulo (index.html, manifest.webmanifest, sw.js, icons folder)
     repo er ROOT e upload koro. Zip file nijei ba folder ta ke upload korle kaj korbe na.
  2. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
  3. 1-2 minute pore address pabe:  https://USERNAME.github.io/REPO-NAME/
  4. Shudhu OI address ta use koro. github.com er file page ba raw.githubusercontent.com er link e install hobe na.

INSTALL KORA
  Android:  Chrome e address ta khulo. Page er upore "Install app" button ashle sheta chap.
            Na ashle Chrome er 3-dot menu > "Install app" ba "Add to Home screen".
  iPhone:   Safari e khulo > Share button > "Add to Home Screen". (iPhone e Chrome diye hobe na.)
  Computer: Chrome/Edge e khulo, address bar er daan dike install icon ba page er "Install app" button.

JODI BUTTON NA ASHE
  - Link ta Messenger/Facebook/WhatsApp er vitore khulle install hobe na. "Open in Chrome" (ba Safari) kore khulo.
  - Address ta https:// diye shuru hocche kina dekho.
  - Browser er purono data clear kore (ba incognito chhara) abar khulo, kichukkhon pore abar try koro.
  - Chrome e address bar e er age ekbar install korle ar dekhabe na (app already install kora).

UPDATE DILE
  index.html bodlano porer bar sw.js er prothom line e  const VERSION = 'zippy-v2';  ke 'zippy-v3' koro.
